# MoneyLog Requirements Traceability

**Audit date:** 2026-10-30. This matrix is the central index of recovered product requirements, decision status, source evidence, and acceptance criteria. Requirements describe intended behavior; source inspection does not confirm that the requirement is correct. “VERIFIED IMPLEMENTED” requires relevant code and completed verification; no feature in this audit qualifies because automated checks did not complete.

## Status meanings

- **Decision status:** CONFIRMED means the user or project decision register explicitly confirms the requirement; NEEDS CONFIRMATION means behavior remains open; DEFERRED means intentionally later scope.
- **Implementation status:** VERIFIED IMPLEMENTED means acceptance criteria were checked successfully; PARTIAL means only some behavior is present or required tests were not executed; VERIFIED MISSING means source inspection found no implementation; UNVERIFIED means available evidence cannot establish behavior.
- Test files listed as evidence are unexecuted test definitions unless their passing execution is explicitly recorded. Source presence alone is not proof of correctness.
